# 真实案例复盘：从错误到策略假设

来源：本项目固定 COLD 测试集；样本 ID 可在 predictions.csv 与本地数据库核查。下列为去标识化概述，不公开攻击原文。参考真值来自数据集，不是本项目人工复审结果；分析为针对实际文本的研究解释，尚未通过新实验验证。

## 1. 反偏见被当成偏见｜cold-test-04302

文本概述：呼吁不要歧视男性。源标签 safe / 反偏见；轻量模型冒犯分数约0.989，二元预测冒犯，级联自动拦截。

问题：表达中出现群体与歧视词，但作者立场是反对歧视。字符特征难以可靠表示否定范围和说话者立场。不能仅通过删除所有群体词解决，否则会漏掉真实攻击。

建议：审核规范单列“反偏见/引用/否定”；建立独立难例验证集；评估语义模型。不能看到这一测试样本后添加“不要歧视=放行”规则并继续声称独立测试成绩。

## 2. 中性身份问句误杀｜cold-test-04777

文本概述：询问是否来自某地区。源标签 safe / 其他非冒犯；分数约0.597，二元预测冒犯，级联转人工。

问题：地区名称与训练语料中的攻击表达形成统计关联，词面模型可能过度依赖身份词。级联弃权避免了此例直接自动拦截，但这不是已获人工纠正的证明。

建议：判断是否存在贬损谓词、泛化归因和攻击目标，不因身份名称本身做处罚；补充中性询问对照样本，进行盲评。

## 3. 群体攻击标签与语境歧义｜cold-test-00689

文本概述：对某地区经济状况作概括评价。源标签 offensive / 群体攻击；模型分数约0.018，二元预测安全，级联自动通过。

问题：该数据集将其标作冒犯，模型漏判；脱离上下文时，事实描述、刻板印象和贬损之间边界可能模糊。不能仅因模型与参考标签不同就断言业务处罚必然正确。

建议：标注规范要求记录概括对象、上下文和贬损依据；争议样本双人复核并仲裁；必要时保留“不足以判断”，不把地域判断扩大为对地域群体的限制。

## 4. 缺乏显式脏词的个人攻击｜cold-test-04139

文本概述：以交易化措辞对具体女性关系作不当暗示。源标签 offensive / 个人攻击；分数约0.028，二元预测安全，级联自动通过。

问题：风险依赖语用和上下文，短关键词表与局部字符权重都容易漏判。补词不一定覆盖隐喻或变体。

建议：补充上下文和针对性攻击标注，评估含蓄表达的独立挑战集，并将低置信语境送审。当前数据没有完整对话，因此无法证明上下文方案的效果。

## 将复盘接入治理

每条案例形成：证据ID → 参考标签与模型差异 → 风险假设 → 标注任务 → 候选策略 → 新留出集评估 → 门禁。此文没有自动改标签，没有把研究解释写入人审完成表，也没有将测试难例加入当前训练。
