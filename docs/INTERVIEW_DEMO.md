# 面试演示：4分钟走完“发现错误—申诉—复核—留痕”

## 演示前准备（不计入讲述时间）

1. 打开线上Demo；进入“申诉与留痕”，点击“重置演示记录”。
2. 返回“真实实验”，准备好GitHub README备用标签页。
3. 确认D02分数为0.9620、初始路由为拦截。分数来自冻结轻量模型实际离线计算，不因演示而修改。
4. 网络不稳定时，在仓库执行 `./run.sh demo` 并打开 http://127.0.0.1:8765 。此模式不需要训练模型或安装机器学习依赖，只需要Python。
5. 不输入姓名、邮箱、手机号等个人信息。审核记录只保存在本浏览器，可重置。

## 演示数据说明

用例文件：`web/demo-cases.json`，8条中文自编文本，均标注 `synthetic_demo`。分数由实际冻结的字符TF-IDF＋逻辑回归模型预计算；网页没有在线推理。建议结论仅为演示作者意见，不是独立人工真值；不计算这些用例的F1，不与COLD混合报告。

D02和D07展示反偏见/引用误杀；D03和D08展示送审；D01、D04、D05展示通过。示例结论不覆盖所有真实语境。

## 面试追问

- **为什么展示失败？** 因为策略运营必须识别上线风险；当前实验无法支持生产自动处罚。
- **为什么网页不是实时AI？** 预计算能稳定展示真实模型结果，无费用与供应商可用性依赖；实时服务及真实LLM评测尚未实施。
- **是否节省78%人工成本？** 不能这样说。78.05%是离线自动决策覆盖率，仍有错误，没有真实成本基线。
- **为什么没有直接修复D02？** 这是后验发现，不能按测试难例改规则后还用同一测试集宣称独立效果；需要新留出集。
- **你实际承担了什么？** 如实说明AI辅助开发，并按本人实际复现、SQL分析、案例复盘和策略设计经历作答，不虚构团队或任职。
- **别人重跑会完全相同吗？** 同机两次输出哈希一致，但首次Linux重跑F1约0.763、待审1,168条，与网页macOS快照存在差异；CI保留差异报告，根因尚未隔离，不能声称跨平台精确复现。
