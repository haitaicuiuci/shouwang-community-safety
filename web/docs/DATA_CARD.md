## 数据含义

官方 train.csv 25,726 / dev.csv 6,431 / test.csv 5,323，共37,480条。训练和验证二元标签：0=safe，1=offensive。测试细标签：0=其他非冒犯，1=攻击个人，2=攻击群体，3=反偏见（safe）。保留 `topic` 和 `source_label`，不把本项目策略分类覆盖源标签。

|来源标签|策略映射|可用范围|
|---|---|---|
|binary 1|冒犯（未细分）|训练/验证|
|binary 0|非冒犯（未细分）|训练/验证|
|fine 1|个人攻击|测试评估切片|
|fine 2|群体攻击|测试评估切片|
|fine 3|反偏见表达，不能直接拦截|测试评估切片|
|fine 0|其他非冒犯|测试评估切片|

源标签是数据集标注参考，不是真实法律裁决或企业社区规则，不应机械视为绝对事实。主实验没有合成数据。单元测试中的少量字符串明确仅为接口测试夹具，不进入任何指标。

## 清洗与划分

保持官方划分；NFKC、小写、只保留字母数字的字符串用于去重哈希，训练输入仍使用原文本。冲突二元标签组整体排除；非冲突组按测试>验证>训练保留一条。同一规范化内容只出现在一个集合中；每条排除原因可查 SQL。

标签冲突检查会读取各集合标签，但不用于选择词表、特征或阈值。特征词表与 IDF 只拟合训练集合；C 与阈值只看验证集；测试预测发生于配置冻结之后。清洗后的测试集并非论文原样评测集。

本方法不检测语义近重复、同作者、主题重叠；标点或表情差异可能被过度合并。无作者身份与可靠时间元数据，因此不能开展按作者隔离、时间外推或真实用户申诉统计。样本不是生产随机抽样，类别比例不代表平台风险率。

## 质量与限制

实际计数见自动生成的 `EXPERIMENT_REPORT.md` 和 `artifacts/quality.json`；每次运行重新生成，不手填业绩数值。训练与验证接近类别均衡，测试中非冒犯比例更高；困难语境和数据分布可能导致阈值迁移失败，原因仍需独立实验验证。

无法评估垃圾营销、色情、诈骗、违法、未成年人保护等细类别；不按性别、地域或种族身份对人评分，仅处理具体文本风险。现有标签不足以做完整的人群公平性结论。
