# 模型卡

名称：char-tfidf-logreg-v1；策略：cold-offline-v1。用途：中文社区冒犯检测的离线学习、运营分析与研究展示，不适用于直接生产处置。

## 已实现

字符 TF-IDF (1–3 gram) 与逻辑回归；朴素关键词规则作基线；验证集选择 C 和二元阈值；验证集分别选择通过与拦截区间。模型输出为二元冒犯分数，未经校准，不是可靠的“违规概率”。没有训练四分类模型，不推测源数据没有的细风险类别。

特征只拟合训练集；训练 liblinear、随机种子42、单数值线程。完整参数在 config/experiment.json；实际冻结值在 artifacts/policy.json；模型与特征打包在 model.joblib。仅从可信本地来源加载 joblib 文件。

## 评估

实际 Precision、Recall、F1、混淆矩阵、切片错误、bootstrap区间见自动生成实验报告。模型在反偏见、否定、引用、短文本与含蓄攻击上表现不足；验证到测试的自动拦截精确率明显下降，当前版本门禁不通过。没有外部验证集、线上 A/B 或用户满意度证据。

级联通过部分样本弃权换取不同覆盖率，不能把自动子集 F1 作为全测试集收益。人审完成前端到端效果为未知，人工队列不读取来源标签作为结论。

## LLM 接口边界

ReviewAdapter 接受文本，返回 decision / risk / confidence / reason；支持 OpenAI-compatible HTTPS chat completion 响应形状，需明确传入 endpoint/model 及环境变量 MODERATION_API_KEY。默认 endpoint=None，没有任何网络调用。

已实现：严格字段与枚举检查、非法/不一致输出拒收、HTTP timeout 参数、有限重试、版本化缓存、哈希化审计、失败转人工；缓存键包括全文哈希、策略、模型、端点与提示版本。无效或失败响应不缓存。审计不记录正文或凭证；缓存会保存供应商 reason，接入后还需检视其是否回显敏感内容。

timeout 是 urllib socket 操作超时，不是严格的总墙钟截止。重试上限是3次尝试；无真实供应商集成测试，不保证所有兼容服务支持 response_format。提示词将输入作为不可信数据，但这不构成提示注入防护有效性的实验证据。

已执行的测试使用明确的 synthetic fixture 和 fake transport 验证控制流，不属于真实 LLM 质量、延迟或可用性评测。当前主实验对所有候选样本调用禁用模式并记录 disabled，随后保持人工待办。

## 后续接入

网络调用需独立配置，主复现流程不会读取凭证自动联网。未来应由产品/算法共同验证供应商条款、上下文最小化、输出规则、并发和总截止机制；用独立人工仲裁集评价。不要把测试真值接入适配器，不把错误自动判为正确。

`src/cascade.py` 提供真正可替换的级联编排函数，无真值参数；调用者注入适配器后可处理LLM输出，低于0.9置信分数或异常仍入人工。该0.9只是接口演示门槛，未做真实LLM校准/验证；主实验始终禁用API。
