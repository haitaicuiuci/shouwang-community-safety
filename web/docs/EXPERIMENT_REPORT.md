本报告由 `src/report.py` 从真实实验产物生成。研究日期：2026-10-21。独立作品集，无企业内部数据、生产流量或上线收益。

## 结论与门禁

轻量模型完整测试集 F1 为 **0.7660**，规则 F1 为 0.0605。模型捕获更多冒犯表达，但误杀仍高。级联只对部分样本自动决策，不能把其自动子集 F1 宣称为全量效果提升。

验证集自动拦截精确率 95.00%（2620 条自动拦截）在测试集降至 **77.11%**。验证集自动通过正确率 95.14%（2677 条）在测试集为 92.72%。门禁未通过，**不得按此结果上线自动拦截**。未使用测试集重新选择阈值。

## 数据与清洗

原始 37480 条；保留 37245 条。训练 25529 / 验证 6405 / 测试 5311。测试安全 3206、冒犯 2105。

NFKC、小写、移除非字母数字字符后 SHA-256 分组，177 条非冲突重复被去除；29 个二元标签冲突组整体剔除；无效或空文本 0 条。跨集合重复组由 105 降至 0。保留优先级 test > validation > train，避免训练接触保留的测试文本；冲突检测使用各集合标签仅作预先定义的数据质量处理。官方测试集发生少量清洗，指标不能与未清洗的论文数字直接比较。

没有作者 ID、时间分组和语义近重复去重，不能保证更广义无泄漏；规范化也可能合并标点或表情含义不同的内容。每个删除项及保留 ID 均在 `quality_exclusions`。

## 配置与选择方法

种子 42。字符 TF-IDF (1–3 gram)、min_df=3、max_features=80000、sublinear_tf=True，仅拟合训练集。逻辑回归 liblinear / max_iter=500 / 单 CPU 线程。C ∈ {0.3,1,3}，二元阈值 ∈ {0.30,0.35,…,0.70}，以验证 F1 选出 C=3.0、阈值 0.45；未将验证集重新加入训练。

级联通过阈值 0.28，拦截阈值 0.72。在验证集扫描 0.01–0.99，分别要求自动通过正确率、自动拦截精确率 ≥95% 且支持数 ≥50，然后最大化各自动区间覆盖；命中规则时禁止自动通过。95% 为经验比例，不是统计置信下界。模型分数未经概率校准。规则词表为事先定义的朴素基线，未针对测试样本扩充；其质量不代表成熟规则系统。

## 质量指标

|cascade_auto_only|4145|77.11%|89.26%|0.8274|2154/417/169/1405|

`cascade_auto_only` 只在有自动结论的 4145 条上计算，排除待复核，不能视为全量端到端结果。人审结论未知，端到端质量记 null。

轻量 F1 分层 Bootstrap 95% 区间 [0.7548, 0.7780]；种子42，400次按真值类别有放回抽样。区间只描述固定模型、固定测试集的抽样波动，不含训练、选择阈值或分布漂移不确定性。

## 路由与人力

全部测试 n=5311：通过 2323（43.74%）；拦截 1822（34.31%）；待人工复核 1166（21.95%）；自动覆盖 78.05%。

自动通过中含冒犯 169，分母为全部通过时污染率 7.28%，分母为全部冒犯时漏放率 8.03%。自动拦截中含安全 417，分母为全部安全时误杀率 13.01%。复核样本没有被假定为正确。

LLM 实际调用 0 次，1166 个不确定样本走禁用适配器并降级到人工队列，审计文件记录 disabled；实验基线人审完成 0 条。队列操作独立持久化，不会修改实验真值或历史指标。规则与轻量模型、离线路由、人工队列已实现；大小模型效果尚未进行联合实测。
